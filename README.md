# 🛒 Victoria’s Shop 🌸✨

## 📌 Description
Console-based shop system with cart, promo code, checkout and JSON saving.

## ✨ Features
- Add / remove products
- Show order
- Promo code (SALE10 -10%)
- Checkout system
- Save order to JSON

## 🧱 Structure
- Shop.h
- Shop.cpp
- main.cpp

## ▶️ Run
1. Open in Visual Studio
2. Build project
3. Run program

## 📋 Menu
1. Add product  
2. Remove product  
3. Show order  
4. Promo code  
5. Checkout  
6. Change status  
7. Save JSON  
0. Exit
